# Credits, cited sources, and asset notes

- **Official challenge**: NASA Space Apps Challenge 2026, "Lunar Landing Site Navigator", https://www.spaceappschallenge.org/2026/challenges/lunar-landing-site-navigator/ (accessed 13 November 2026).
- **NASA/JPL Horizons manual**: https://ssd.jpl.nasa.gov/horizons/manual.html (geodetic lunar sites, observer ephemerides, azimuth/elevation definitions).
- **NASA/JPL Horizons API documentation**: https://ssd-api.jpl.nasa.gov/doc/horizons.html and fair-use restrictions https://ssd-api.jpl.nasa.gov/ . The supplied data-retrieval script is original application code; NASA/JPL data remain NASA/JPL source information.
- **Lunar reconnaissance/topography resource**: NASA LRO/LOLA https://pds-geosciences.wustl.edu/missions/lro/lola.htm . Referenced only: **no LOLA DEM is bundled or used by default**.
- **LROC Quickmap (official challenge resource)**: https://quickmap.lroc.asu.edu/ . Used as a reference for exploring lunar imagery and topography; LUNARIS does **not** download, embed, or georeference its map tiles in this package.
- **NASA Moon Trek (official challenge resource)**: https://trek.nasa.gov/moon/ . Referenced for lunar exploration and terrain; no map, 3D assets, or analysis products from Trek are bundled.
- **Canadian Space Agency Moon Exploration (official partner resource)**: https://www.asc-csa.gc.ca/eng/astronomy/moon-exploration/ . Background/reference only, no CSA data are embedded.
- **Lunar classroom references**: NASA *Exploring the Moon: A Teacher's Guide* (NASA EG-1997-10-116-HQ), and user-provided Moon / Sun / Earth classroom PDFs. These provided background explanations only; the site does not present their diagrams as ephemerides.
- **Texture `assets/moon-texture.jpg`**: copied from lunar texture already supplied in the user's project files; visually generated/illustrative; **not** NASA mission photography or a calibrated LOLA elevation map. The contributor should confirm artwork rights before public submission.
- **Favicon / interface / HTML / JavaScript / CSS**: original implementation prepared for Team CodexGalaxy, 2026. No NASA endorsement implied.
- **Fonts**: The app uses local system font fallbacks and downloads no web fonts. No font files are bundled.

No NASA emblem or official insignia is included. The phrase "NASA Space Apps Challenge" identifies the competition.
