# CREDITS — LUNARIS 2026

**Project:** Team CodexGalaxy — LUNARIS — Lunar Landing Site Navigator, NASA Space Apps Challenge 2026. This is an **independent participant project**, not an agency-operated or agency-endorsed application.

## Official challenge resources

- NASA Space Apps Challenge 2026, **Lunar Landing Site Navigator**: https://www.spaceappschallenge.org/2026/challenges/lunar-landing-site-navigator/
- **NASA/JPL Horizons**: https://ssd.jpl.nasa.gov/horizons/ ; API docs https://ssd-api.jpl.nasa.gov/doc/horizons.html . Used as the supported source for ephemeris import/caching. **The default package does not contain validated NASA sample output**.
- **LROC Quickmap**, Arizona State University: https://quickmap.lroc.asu.edu/ . Official challenge resource link and research reference only; no map tiles or DEM bundled.
- **NASA Moon Trek**: https://trek.nasa.gov/moon/ . Official challenge link and research reference only; no Moon Trek data or imagery embedded.
- **Canadian Space Agency Moon Exploration**: https://www.asc-csa.gc.ca/eng/astronomy/moon-exploration/ . Official partner resource for background only, no CSA scientific samples bundled.
- **NASA LRO LOLA**: https://pds-geosciences.wustl.edu/missions/lro/lola.htm . Referenced planned elevation data only, **not integrated**.

## Landing sites and coordinates

- NASA NSSDC **Apollo landing-site lunar module coordinates**, DE421 Mean Earth/Polar Axis frame: https://nssdc.gsfc.nasa.gov/planetary/lunar/lunar_sites.html
- ISRO **Chandrayaan-3** project landing references: https://www.isro.gov.in/ISRO_EN/Chandrayaan3_Details.html
- COSPAR international lunar landing-site reference/coordinates (Chang'e, IM-1, Chandrayaan-3): https://cosparhq.cnes.fr/assets/uploads/2024/09/COSPAR-PPP-2024-Overview.pdf
- South Pole Reference / Polar Ridge A / Polar Basin B / Polar Plateau C: **invented demonstration/reference coordinates**, not actual terrain-qualified locations.

## Visual assets

- `assets/moon-texture.jpg`: supplied in the user's project archive; an **illustrative, non-georeferenced lunar texture**, not calibrated NASA terrain. The team must confirm rights to the original artwork before submission.
- `assets/earth-map.jpg`: illustrative texture generated by this project using generalized land boundaries from **Natural Earth** low-resolution world coastline/country geometry, public domain: https://www.naturalearthdata.com/about/terms-of-use/ . Color grading, clouds, lighting and shading are computer-generated. **It is not a NASA Earth photograph or a measured Earth dataset**.
- Sun sphere: original CSS-generated illustration, not measured solar imagery.
- 3D Moon visualization: original WebGL shader/sphere renderer, with 2D landmark projection.
- `assets/favicon.svg`: original project artwork.

## Licenses and usage

The original LUNARIS source code is included under the repository's MIT license. Scientific references retain their publisher/source notices and data-use parameters. Verify any NASA, ASU/LROC, CSA and other external resource terms before redistributing third-party materials. No official NASA insignia or emblem is included.

**Transparency:** All numerical Sun/Earth results **default to analytical estimates** unless an independently generated Horizons catalog is imported for the selected site and date window. Synthetic terrain and simplified power estimates are not verified NASA datasets, and no measured terrain-horizon algorithm is implemented in this release.
