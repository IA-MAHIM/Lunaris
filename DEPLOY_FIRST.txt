LUNARIS 2026 — UPDATED WEBSITE / GITHUB PAGES
===========================================

Existing repository: https://github.com/IA-MAHIM/Lunaris
Published site:     https://ia-mahim.github.io/Lunaris/

1. EXTRACT this ZIP.
2. Open your GitHub repository → Code → Add file → Upload files.
3. Upload ALL EXTRACTED FILES to the repository root (NOT the ZIP).
   Replace existing index.html, app.js, physics.js, moon3d.js,
   styles.css, README.md, assets/ and all other matching files.
   IMPORTANT: Upload the NEW design.css and assets/earth-map.jpg.
4. Click Commit changes to MAIN.
5. Keep Settings → Pages → Deploy from branch → main → /(root).
6. Reload your live site with Ctrl+Shift+R.

CHECK THESE SCREENS:
  Overview → Mission Planner → Visibility Analysis → Compare 4 Missions
  → Data & Methods → Final Report

TRY THIS:
  Planner: select Apollo 11, date 2026-12-05, duration 5 days,
  click Analyze visibility. Then click Compare up to 4 missions.
  Change three alternate sites and dates and click Compare all.
  Then open Data & Methods and Final Report.
  Download the .md report and .csv time series.
