# 🌕 LUNARIS — Lunar Mission Planning & Simulation

**NASA Space Apps Challenge 2026 | Team CodexGalaxy**

LUNARIS is a web-based lunar mission planning and visualization platform developed by Team CodexGalaxy, a group of Computer Science and Engineering students from IUBAT, Dhaka, Bangladesh.

We built this project for NASA's **Lunar Landing Site Navigator** challenge to make lunar exploration and mission planning easier to understand. Our main focus is helping users explore different Moon landing locations, select mission dates, and examine how sunlight and Earth visibility can affect lunar surface operations.

### 🚀 What Our Website Does

- Explore an interactive 3D Moon and select landing locations.
- Choose mission dates and durations.
- Analyze estimated sunlight and Earth communication windows.
- Compare up to four different mission scenarios.
- Explore mission timing and basic power conditions.
- Generate and download mission analysis reports.

### 🛠️ Technologies Used

HTML, CSS, JavaScript, WebGL, and publicly available lunar science resources.

### 🛰️ Data and Resources

Our project references NASA/JPL Horizons, LROC Quickmap, NASA Moon Trek, and lunar topography resources. The current demonstration uses simplified calculations, with support for importing JPL Horizons data. Terrain visualization is not yet a fully validated topographic model.
